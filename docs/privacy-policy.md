# 隐私政策（codemagic · iOS）

生效日期：2026-11-07
适用版本：`0.28.0`（build 37）

本政策只描述 **当前版本已实现** 的数据处理。codemagic 由本 App 的开发者（以下称「我们」）提供；如有疑问，可通过 App Store 商品页展示的开发者联系方式与我们联系。

## 1. 一句话说明

codemagic 用蓝牙读取附近设备的读数，并把设备、读数与规则同步到一个 **匿名账号**。我们不投放广告、不接入分析 SDK、不收集位置，也不要求账号密码。

## 2. 我们收集哪些数据

| 数据项 | 具体字段 | 来源 | 用途 | 是否与服务端匿名账号关联 | 用于追踪 |
| --- | --- | --- | --- | --- | --- |
| BLE 设备标识 | `CBPeripheral.identifier`（以大写 UUID 作为 `externalId`） | 系统蓝牙扫描 | 区分设备、重连、跨启动识别同一设备、同步 | 是 | 否 |
| 设备广播名与别名 | `advertisedName`（BLE Local Name）、`remark`（用户备注）、`groupName`（用户分组） | 蓝牙广播 / 用户输入 | 列表展示、搜索、分组、同步 | 是 | 否 |
| 读数与时间戳 | 心率、电量、温度及 Nordic UART 解析出的指标值、单位、`recordedAt` | 设备 notify | 首页最近读数、历史曲线、阈值判断、导出、同步 | 是 | 否 |
| 规则与触发记录 | 规则类型（断开 / RSSI / 指标越界）、阈值、启停状态、触发时间与原因 | 用户创建 / 规则引擎 | 自动化与「最近触发」展示、同步 | 是 | 否 |
| 本地扫描日志 | 分类、级别、发生时间、消息（不含位置） | App 运行记录 | 本机排查同步与规则问题 | 否（仅本机） | 否 |
| 匿名账号 ID 与 token | 服务端生成的匿名 `userId`；Keychain 中的 token | 首次匿名登录 | 身份识别、同步鉴权、注销 | 是（token 本身） | 否 |
| 同步元数据 | 游标、上次同步时间、客户端标识 `clientId` | App 运行 | 增量同步、诊断 | `clientId` 随账号请求发送 | 否 |
| 家庭与房间关系 | 家庭名、房间名、成员 `userId`、角色（owner / member） | 用户输入 / 服务端 | 家庭与房间管理、设备归属、同步 | 是 | 否 |
| 反馈内容 | 主题、正文、可选联系方式、App 版本 / iOS 版本 / 设备型号 | 用户主动提交 | 处理反馈与排查问题 | 是 | 否 |
| APNs 推送令牌 | `push_devices.token`、远端 `deviceId`、状态与最后错误 | 系统 `registerForRemoteNotifications` | 阈值告警推送、注册失败排查 | 将来启用推送后与匿名账号关联 | 否 |

> **当前版本（0.28.0/build 37）不采集 APNs 推送令牌**：App 没有 `aps-environment` entitlement 与推送证书，系统不会下发令牌，`push_devices` 只保存「未配置推送」状态与错误，界面同样如实显示。只有配置推送证书后才开始采集；届时本表、第 7 节与商店隐私问卷会同步改为「已采集」。

说明：

- **心率** 属于与健康相关的数据，仅用于读数展示、曲线与阈值判断；本 App 不是医疗设备，不做诊断或治疗建议。
- 我们不收集精确或粗略位置。`Info.plist` **没有** 任何 `NSLocation*` 声明，代码不调用 `CLLocationManager`，蓝牙扫描也不需要定位权限。
- 我们不收集通讯录、照片、麦克风、广告标识符（IDFA），也不读取剪贴板。
- 本 App 无账号密码登录，不收集手机号、邮箱或密码。

## 3. 数据存放在哪里

**本机（iPhone）**

- SQLite：`Application Support/com.platojobs.codemagic/codemagic.sqlite`，保存设备、读数、规则、场景、家庭与房间、反馈草稿、推送令牌注册状态（`push_devices`）与同步状态。
- `UserDefaults`：保存开关类偏好（排序、分组筛选、后台采集、通知与告警开关、首启引导进度）与同步元数据。
- Keychain：保存匿名账号 token，使用 `kSecClassGenericPassword` 与 `kSecAttrAccessibleAfterFirstUnlock`，不在 `UserDefaults` 中保存凭据。

**服务端**

- 设备（`platform=ios` + `externalId`、广播名、别名、分组）、读数与时间戳、规则与触发记录、扫描日志，均与匿名账号关联。
- 家庭与房间（含成员 `userId` 与角色）、反馈内容（含可选联系方式与客户端诊断）、已注册的推送设备（`push_devices`），均与匿名账号关联。
- token 由服务端签发，仅用于同步鉴权；Release 构建通过 **HTTPS** 访问服务端。

## 4. 保留期

| 数据 | 保留期 |
| --- | --- |
| 服务端读数 | **90 天** |
| 本机已同步读数 | **7 天**（App 启动与每次同步成功后清理早于 7 天且已同步的记录） |
| 本机未同步读数 | 保留至补传成功，避免离线期间静默丢数据 |
| 设备、别名、分组、规则、场景 | 保留至你在 App 内删除，或注销账号 |
| 家庭、房间、成员关系 | 保留至你退出 / 删除家庭，或注销账号 |
| 反馈 | 提交后保留至处理完成；注销账号时一并删除 |
| 推送设备（`push_devices`） | 登出或注销前先置为 `inactive`；注销账号时随账号删除 |
| 本机扫描日志 | 保留至你在「我的 → 本地扫描日志」清空，或注销账号 |
| 匿名账号与 token | 保留至你在 App 内注销账号 |

## 5. 注销即删除

「我的 → 注销账号」会调用 `DELETE /api/v1/me`。成功后：

1. 先调用 `DELETE /api/v1/push/devices/{deviceId}` 停用已注册的推送设备（404 视为已不存在）；
2. 服务端删除该匿名账号及其设备、读数、规则、家庭、日志、反馈与推送设备记录；
3. 本机删除 Keychain token；
4. 本机清空全部业务表（含 `scenarios` 与 `push_devices`）与同步元数据。

注销不可恢复。网络失败或 token 已失效时，App 会明确提示，并且 **不会** 静默清空本机数据。

## 6. 共享与出售

- 我们 **不出售** 你的数据，也不向广告商、数据经纪商共享。
- 数据只发送到本 App 配置的服务端，用于同步与账号功能。
- 导出功能由你主动触发：CSV 写入临时文件，经系统分享面板交给你选择的目标；分享完成后 App 会清理临时文件。

## 7. 通知

- 阈值告警默认使用 **本地通知**（`UNUserNotificationCenter`），由设备读数在本机触发。
- **当前版本不采集 APNs 令牌**：App 与签名配置中都没有 `aps-environment` entitlement，也没有推送证书，`registerForRemoteNotifications` 不会得到令牌；本地 `push_devices` 只记录「未配置推送」状态与错误，不上报任何占位值，界面如实显示「未配置推送」。
- 将来配置推送证书与 entitlement 后，App 会把 APNs 设备令牌注册到本 App 的服务端，用于发送阈值告警类远程通知。启用时需同步更新本政策第 2、7 节、`docs/app-privacy.md`、`docs/store-listing.md` 与商店隐私问卷（APNs 令牌仍归入「标识符 → 设备 ID」，`Linked = Yes`、`Tracking = No`、用途 App Functionality）；未完成这些更新前，商店申报必须保持「当前不采集」。
- 推送令牌只用于告警投递，不用于营销；通知权限与注册解耦，拒绝通知权限仍会尝试注册令牌，但通知不会展示。
- 通知权限可随时在系统设置关闭；关闭后规则仍会在「智能」页记录触发历史。

## 8. 后台采集

- `Info.plist` 声明 `bluetooth-central` 与 `fetch`。
- 后台读数只在设备保持连接时继续；iOS 可能延后唤醒，断开连接后停止采集。
- 可在「我的」关闭后台采集，关闭后进入后台会断开连接。

## 9. 安全

- token 仅存 Keychain；Release 网络流量走 HTTPS。
- 本机数据库位于 App 沙盒内，不与其他 App 共享。
- 受 iOS 平台能力限制，任何本机存储都无法承诺绝对安全；请同时使用设备锁屏密码与系统更新。

## 10. 儿童

本 App 不面向儿童设计，不主动收集儿童个人信息。若监护人发现儿童向我们提供了个人信息，可通过商品页联系方式要求删除。

## 11. 政策更新

功能变化导致数据处理发生变化时，我们会更新本政策与 App 内声明，并在新版本发布说明中注明。当前版本无广告、无分析 SDK、无位置权限、无账号密码登录。
