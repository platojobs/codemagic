## 蓝牙与连接

- [ ] 首次启动触发系统蓝牙授权；拒绝后「我的」显示明确引导，可跳系统设置。
- [ ] 真机扫描能发现设备并显示名称 / RSSI；离开范围后「断开」规则触发一次。
- [ ] 连接成功后读取特征值；12s 内未完成连接则超时并给出可重试提示。
- [ ] 未连接设备的首页卡不显示信号格；详情仍可见最近一次读数与读数时间。

## 后台与推送

- [ ] 真机进入后台后 `BGAppRefreshTask` 能执行（模拟器不支持）。
- [ ] 通知权限允许后，规则触发收到本地通知；恢复后再收到一条恢复通知。
- [ ] APNs 注册成功，「我的」显示令牌状态；注销后服务端 `push_devices` 置 `inactive`。

## 账号与同步

- [ ] 断网时本地读写正常；恢复后增量同步，冲突提示「另一台设备改过这条」。
- [ ] 401 后手动「重新登录」，游标重置、本机设备重新上传。
- [ ] 删除账号需两步令牌；删除后业务表与缓存清空，重启不复活。
- [ ] 导出任务可下载一次性链接；过期后自动换新链接一次。
